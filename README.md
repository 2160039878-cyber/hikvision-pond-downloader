# 海康鱼池录像下载工具

Windows 本机网页工具。支持 1-1～1-8、2-1～2-8 多选、任意起止时间或每日多个时间点、目录选择、任务预览、取消和失败恢复、历史记录及在线播放。

## 启动

1. 安装 Node.js 20 或更新版本，确保 `node` 可在命令行运行。
2. 安装 FFmpeg，确保 `ffmpeg` 和 `ffprobe` 在 PATH 中。
3. 准备合法获取的 64 位海康 HCNetSDK 及配套组件。SDK 和 FFmpeg 二进制不包含在仓库中。
4. 下载并完整解压源码，双击 `开始.cmd`（或 `Start.cmd`）。
5. 在页面配置实际设备 IPv4、SDK 端口、SDK 目录和每个鱼池的真实通道。示例地址 `192.0.2.1` 不是真实设备地址，所有通道默认未绑定。
6. 选择鱼池、时间、保存和缓存目录，输入设备凭据，预览后开始。每个鱼池先下载短片核实画面，不能按编号推算通道。

通用 iVMS 安装路径只是默认提示，需要根据实际安装位置修改。SDK 对中文路径有限制；缓存可选英文目录，最终保存目录支持中文。

## 下载与校验

原始流下载到缓存，转码为 H.264 MP4（有音频时 AAC）；QSV 不可用时回退软件编码。快速校验容器、编码、时长及首帧，复制目标临时文件并比对大小和 SHA256 后才完成。成功后清理缓存，失败保留恢复资料，不覆盖冲突文件。

快速校验不代表全片无损坏。超过一小时的范围分段处理；关闭网页不终止下载，主机须保持开机。程序重启后未完成任务标为中断，由用户恢复。恢复按片段及哈希进行，不承诺原始流字节级续传。

## 安全与数据边界

仅监听 127.0.0.1，检查 Host、Origin 和会话令牌。当前版本没有远程访问或多人账号功能，请勿直接开放公网端口。

密码仅通过运行内存和工作进程标准输入传递，不写入任务文件。运行时的 `data/`、目标目录清单、校验报告以及浏览器保存的目录偏好仍可能包含设备地址、路径及录像时间，不应上传仓库。

仓库是独立脱敏副本：不含现场地址、实际通道映射、用户名、录像、截图、运行历史或原始验收报告。原现场版本的实机结果不代表任意新设备均已通过验收。

## 验证

执行 `npm test`。测试使用合成视频、示例通道和临时目录，不连接录像机；覆盖时间拆段、映射限制、转码与校验、中文路径、哈希冲突、取消、来源验证、视频 Range 和中断恢复。真实设备兼容性需使用者另行短片验收。
