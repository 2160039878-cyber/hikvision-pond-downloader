# 海康录像下载助手 2.0 预览版

这是 Windows x64 独立窗口版。当前为预览交付，**不是所有电脑都能直接下载的完整免安装版**：包内包含桌面运行时、FFmpeg 和 FFprobe，不含海康 SDK。优先自动检测本机已有 iVMS 的 64 位 SDK；未检测到时，可在设备与设置中选择合法取得的 SDK 文件夹。

## 普通用户

1. 完整解压后双击“开始.exe”，保留旁边的“程序”文件夹。
2. 点击“添加第一台设备”，输入录像机名称、地址、端口和凭据。密码默认只保存在本次运行内存；勾选后通过 Windows 当前用户加密。
3. 软件读取设备实际通道和名称。未配置通道会在支持的设备上被过滤；不支持状态查询时显示“状态未知”，不能误认为在线。
4. 选择一台或多台录像机中的摄像头，设置连续区间或每日定点，选择保存目录。
5. 查询并预览任务；明确无录像的片段不下载。查询失败时需勾选确认才继续尝试。
6. 加入队列后，任务串行下载、转码、校验及保存。完成后可播放、打开文件夹或重新校验。

所有时间按各录像机自己的本地时间解释，不自动校时。10 秒画面确认创建短片预览，提交下载完成后播放；不提供实时监控。

关闭窗口会收起到托盘，任务继续。右键托盘选择退出会取消当前操作并保存状态；下次启动请恢复任务。未记住密码的设备需要重新输入密码，其他设备可继续下载。不要在系统清理软件中清理应用数据或失败任务缓存。

程序数据保存在当前 Windows 用户的应用数据目录；解压目录只存程序。密码加密不能抵御同一 Windows 用户权限下的恶意程序。换用户或换电脑后需要重新输入密码。

手动通道配置属于兼容模式。旧配置导入需要补充用户名和密码，不导入历史任务或原密码。原 1.1 工具独立保留。

## 开发与验证

在 desktop 目录执行 `npm ci`、`npm start`；根目录 `node --test --test-concurrency=1 test.mjs desktop/desktop.test.mjs` 执行回归。Electron 精确版本由锁文件固定。Windows 子进程测试按文件串行执行，避免同时运行多套进程退出测试。

打包：`node desktop/package.mjs <新输出目录> <已验证的FFmpeg解压目录>`。输出目录必须不存在，脚本不覆盖旧包、不包含 SDK 或现场状态。

该版本不开放远程控制接口，不修改录像机配置，不包含自动更新、手机端或其他品牌接入。支持型号以验收记录为准。当前 Windows 环境内的测试不能代替干净 Windows 10/11、两台真实录像机及全部异常场景的验收。

## 校验规则

输出 H.264 MP4，有音频时 AAC；快速校验容器、编码、时长、首帧。时长容差为请求时长的 2%，最低 1 秒、最高 10 秒。目标临时文件大小与 SHA256 一致后才转为正式文件。快速校验不代表全片无损坏，移动盘异常和冲突文件不自动修复或覆盖。

## 发布限制

完整免安装包因 SDK 分发条件未确认而停止发布；FFmpeg 完整对应源码和构建材料亦须在对外二进制 Release 前落实。详见许可说明。不要求关闭杀毒软件或绕过 Windows 安全提示。
