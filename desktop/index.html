设置时间与保存位置

按各录像机本地时间解释。跨设备不自动校时；超过一小时按小时拆段。

确认下载任务

任务列表

选择左侧任务查看进度与录像。

你的录像机

每台设备独立保存；密码由你决定是否记住。

保存与环境

SDK 缓存路径需能转换为英文短路径。成功后清理本次缓存，失败保留恢复资料。

高级设置与预览版说明

本预览版不分发海康 SDK。自动检测本机已有 iVMS；没有检测到时，请选择你合法获取的 64 位 SDK 所在文件夹。

“记住密码”使用 Windows 当前用户加密保护，不抵御同一用户权限下的恶意程序。关闭窗口后任务在托盘继续，退出软件会保存并停止任务。
